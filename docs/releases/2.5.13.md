# Employees 2.5.13

This release makes the latest upstream application usable on PostgreSQL and
adds native per-user English and Russian localization through Nextcloud.

## Compatibility

- The technical application ID remains `empleados`.
- The PHP namespace remains `OCA\Empleados`.
- Database queries use the lowercase identifiers physically created by
  Nextcloud on PostgreSQL.
- Legacy mixed-case response keys are retained during the compatibility period.

## Localization

- English title: `Employees`
- Russian title: `Сотрудники`
- English and Russian catalogues contain the same 1,698 keys.
- The active catalogue is selected by the user's Nextcloud language.
